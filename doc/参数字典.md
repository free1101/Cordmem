# 参数字典（src/config.py · ServerConfig）

> 唯一真相来源：`src/config.py` 的 `ServerConfig` + `_SPECS` 校验表。本文与其同步维护（最近更新：2026-10-23，加入 PRF / MMR / 句级三组）。
> 每个参数都可以通过三种来源设置，优先级从高到低：**CLI `--set` / override > YAML `server:` 段 > 环境变量 > dataclass 默认值**。
> YAML 里声明过的字段，同名环境变量会被忽略并打 WARNING（防止本机残留 env 静默盖掉 YAML）。

## 快速参考：三源写法

```powershell
# 1) 环境变量（YAML 没声明该字段时才生效）
$env:MEMORY_RERANK_ENABLED = 'true'

# 2) YAML（configs/*.yaml 的 server: 段）
# server:
#   retrieval_mode: hybrid
#   fuse_strategy: rrf

# 3) CLI --set（注意：多个 k=v 跟在【一个】--set 后面，nargs='*'）
python local_eval/run_eval.py --set mmr_enabled=true session_quota_enabled=true
```

**非法值直接抛 `ConfigError`**（枚举白名单 / 数值区间 / bool 字面量白名单 / 未知字段名都会拦），不会静默吞掉。

## 「重灌」标记说明

- **重灌** = 改了它必须重灌库（重建 `memories.db`），已列入 `local_eval/db_info.py` 的 `REBUILD_ON_CHANGE` 指纹；其中 `embedding_*` / `context_messages` 变了还会被 `store._check_identity()` 直接拒绝打开旧库。
- **检索期** = 随便改、不用重灌（`REUSE_SAFE`），只影响当次检索的打分与排序。
- 未标记的参数属运行配置（库路径、输出位置等），不参与复用判定。

| `embedding_backend` | `EMBEDDING_BACKEND` | choice `local`/`api` · `local` | local = 进程内 sentence-transformers；api = OpenAI 兼容 `/embeddings` |
| `embedding_api_base` | `EMBEDDING_API_BASE` | str · `""` | api 后端的端点，如 `https://api.siliconflow.cn/v1` |

## 3. 切块（改任何一项 = 重灌；注意 `mem_id` 与 chunk 边界会静默错位）

| 字段 | 环境变量 | 类型 / 默认值 | 说明 |
| --- | --- | --- | --- |

| --- | --- | --- | --- |
| `fuse_strategy` | `MEMORY_FUSE_STRATEGY` | choice `weighted`/`rrf` · `rrf` | rrf = 名次融合（R1 dense 基准 1.0 + R2 词法 `lexical_weight`）；weighted = 归一加权 |
| `rrf_k` | `MEMORY_RRF_K` | int ≥1 · `60` | RRF 名次衰减常数（**仅 rrf 生效**） |
| `lexical_weight` | `MEMORY_LEXICAL_WEIGHT` | float ≥0 · `0.5` | R2 词法路权重（**仅 rrf 生效**） |
| `bm25_weight` | `MEMORY_BM25_WEIGHT` | float ≥0 · `0.4` | BM25 权重（**仅 weighted 生效**） |
| `vector_weight` | `MEMORY_VECTOR_WEIGHT` | float ≥0 · `0.6` | dense 权重（**仅 weighted 生效**；dense-only 模式下 ≤0 时兜底 1.0） |
| `retrieval_recall_n` | `MEMORY_RETRIEVAL_RECALL_N` | int ≥1 · `300` | BM25 路截断上限——仅在真会走 rerank 时生效（对齐 vanilla 0.6.0） |

## 8. PRF / Rocchio 查询扩展（默认关，检索期）

| 字段 | 环境变量 | 类型 / 默认值 | 说明 |
| --- | --- | --- | --- |
| `prf_enabled` | `MEMORY_PRF_ENABLED` | bool · `False` | 用首轮 dense top-k 质心扩展 query 向量 `q' = normalize(q + β·mean(topk))`，替换重算 dense 分。BM25 路不动。命门：首轮被闲聊霸榜时质心被带偏 → 与 MMR 配套开 |
| `prf_beta` | `MEMORY_PRF_BETA` | float 0~2 · `0.5` | 挪多大一步；0 = 等价关闭（debug 记 `noop=zero_beta`）。常用 0.3~0.8 |
| `prf_topk` | `MEMORY_PRF_TOPK` | int ≥1 · `5` | 首轮取几条做质心；越大越贴语料区域，越小越抗噪 |

## 9. MMR 去冗余 + session 软配额（默认关，检索期）

| 字段 | 环境变量 | 类型 / 默认值 | 说明 |
| --- | --- | --- | --- |
| `mmr_enabled` | `MEMORY_MMR_ENABLED` | bool · `False` | 融合后贪心 MMR：`λ·sim(q,d) − (1−λ)·max sim(d,已选)`。只重排顺序（选中者排前、其余按原融合序跟后），不改分数与条数；在 rerank/adjacency 之前 |
| `mmr_lambda` | `MEMORY_MMR_LAMBDA` | float 0~1 · `0.6` | λ=1 退化纯相关排序；0.5~0.7 常用 |
| `mmr_candidate_n` | `MEMORY_MMR_CANDIDATE_N` | int ≥0 · `0` | MMR 候选池大小；0 = 用 `rerank_recall_n` 当池 |
| `session_quota_enabled` | `MEMORY_SESSION_QUOTA_ENABLED` | bool · `False` | 软配额两阶段：先守「每 session 最多 N 条」选满 top_k，候选 session 不足时放开补选（防 top-k 空洞）。两阶段共用同一套 MMR 打分 |
| `session_quota_n` | `MEMORY_SESSION_QUOTA_N` | int ≥1 · `1` | 每 `session_id` 最多 N 条。N=1~2 对闲聊霸榜最直接 |

## 10. 多粒度索引：句级向量（灌库侧开关改了 = 重灌）

| 字段 | 环境变量 | 类型 / 默认值 | 说明 |
| --- | --- | --- | --- |
| `sent_index_enabled` | `MEMORY_SENT_INDEX_ENABLED` | bool · `False` | **灌库侧**：切 chunk 同时切句编码，写新表 `memory_sentences`（FK→`memories.id`）。不改 `mem_id`、不触发 `_check_identity`，但已列入 `REBUILD_ON_CHANGE`——旧库没有句级行，开它必须重灌。编码量/请求数约 ×10~15（token 量约 ×2） |
| `sent_rescore_enabled` | `MEMORY_SENT_RESCORE_ENABLED` | bool · `False` | **检索侧**：句级分数按 `sent_pool` 聚合，乘性加成 `fused *= (1 + sent_weight·pool)`。无句级行自动 no-op（打一次警告） |
| `sent_pool` | `MEMORY_SENT_POOL` | choice `max`/`mean`/`blend` · `max` | 聚合方式：max 对关键句最敏感（放大小噪声）；mean 平稳；blend 压噪 |

## 附录 B：改了必须重灌的完整清单（`REBUILD_ON_CHANGE`）

```
embedding_model / embedding_backend / embedding_api_base / embedding_api_dimensions
embedding_query_prefix / embedding_max_seq_length / context_messages
chunk_tokens / chunk_overlap / drop_short_tail
sent_index_enabled
```

其余全部为检索期参数（`REUSE_SAFE`），改了不用重灌。复用某次 run 的库：`--db-path <run目录>/memories.db --skip-add`，启动时 `check_reuse()` 会打印「可复用 / 不可复用（差在哪） / 不确定」。
